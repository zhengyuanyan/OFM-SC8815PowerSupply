# 总线电源 应用说明

总线电源应用允许使用 ETS 对诊断参数进行参数化。

## **所用模块**

总线电源使用了其他 OpenKNX 模块，这些模块都有自己的文档。下面列出这些模块及其文档链接。

### **OpenKNX**

这是通用参数页面，详见 [Applikationsbeschreibung-Common](https://github.com/OpenKNX/OGM-Common/blob/v1/doc/Applikationsbeschreibung-Common.md)。

### **配置传输**

配置传输支持

* 导出 OpenKNX 模块及其通道的配置
* 导入 OpenKNX 模块及其通道的配置
* 将一个 OpenKNX 模块通道的配置复制到另一个通道
* 将 OpenKNX 模块通道的配置恢复为默认值

配置传输模块的功能详见 [Applikationsbeschreibung-ConfigTransfer](https://github.com/OpenKNX/OFM-ConfigTransfer/blob/v1/doc/Applikationsbeschreibung-ConfigTransfer.md)。

### **逻辑**

与大多数 OpenKNX 应用一样，本应用也包含逻辑模块。

逻辑模块的功能详见 [Applikationsbeschreibung-Logik](https://github.com/OpenKNX/OFM-LogicModule/blob/v1/doc/Applikationsbeschreibung-Logik.md)。

## **总线电源**

<!-- DOC HelpContext="Dokumentation" -->
使用本模块可以配置总线电源的诊断参数等。

总线电源由两块独立的 SC8815 芯片组成：一块为 KNX 总线供电（总线电源），一块提供辅助电源（辅助电源，AUX）。两块芯片的输入电压/电流、输出、开关频率、芯片温度都可以单独设置与上报，因此在 ETS 中分成“SC8815 总线电源”和“SC8815 辅助电源”两个页面。

### **SC8815 总线电源**

该页面包含总线侧（为 KNX 总线供电）的设置与上报对象。

#### **设置**

在此可以进行所有通用设置。

<!-- DOC HelpContext="Resetzeit" -->
##### **复位时间**

电源模块前端有一个按钮，用于触发总线复位。也可以通过通信对象触发复位。

在此设置复位时间，即复位期间总线电压保持断电的秒数。

#### **SC8815 设置**

在此设置 SC8815 直流变换器的参数。这些参数只在设备启动时生效。

<!-- DOC HelpContext="SC8815-Busstrom" -->
##### **总线电源电流**

通过 SC8815 为 KNX 总线提供的电流上限。

可选值：640 mA、960 mA、1280 mA。

该值表示总线电源可供总线设备使用的最大电流，请根据实际使用的电源和总线负载进行选择。

<!-- DOC HelpContext="SC8815-Frequenz" -->
##### **开关频率**

SC8815 的开关频率。

可选值：150 kHz、300 kHz、450 kHz。

频率越高，所需的外围电感/电容可以越小，但开关损耗越大；频率越低则相反。通常保持默认值 300 kHz 即可。

#### **输入**

下面可以启用总线侧 SC8815 的输入电压/电流上报。“相对最小变化量”“绝对最小变化量”“周期发送”的含义与输出相同。

<!-- DOC HelpContext="Eingangsspannung-senden" -->
##### **发送总线电源输入电压**

在此设置是否输出总线侧 SC8815 的输入电压。

打开后，下面设置的“相对最小变化量”“绝对最小变化量”“周期发送”只对输入电压生效，电压值通过“总线电源输入电压”通信对象上报。

<!-- DOC HelpContext="Eingangsstrom-senden" -->
##### **发送总线电源输入电流**

在此设置是否输出总线侧 SC8815 的输入电流。

打开后，下面设置的“相对最小变化量”“绝对最小变化量”“周期发送”只对输入电流生效，电流值通过“总线电源输入电流”通信对象上报。

#### **输出**

下面可以启用总线侧的各种输出功能。

<!-- DOC HelpContext="Status-Netzteil-senden" -->
##### **发送总线电源状态**

在此设置是否输出总线电源的状态。

<!-- DOC HelpContext="Busspannung-senden" -->
##### **发送总线电压**

在此设置是否输出总线电压。

<!-- DOC HelpContext="Busstrom-senden" -->
##### **发送总线电流**

在此设置是否输出总线电流。

<!-- DOC HelpContext="Busauslastung-senden" -->
##### **发送总线负载**

在此设置是否输出总线负载。

<!-- DOC HelpContext="Temperatur-senden" -->
##### **发送总线电源温度**

在此设置是否输出总线侧 SC8815 芯片自带温度传感器的温度值。

打开后，下面设置的“相对最小变化量”“绝对最小变化量”“周期发送”只对该温度生效，温度值通过“总线电源温度”通信对象上报。

辅助电源那块芯片的温度属于“SC8815 辅助电源”页面，它有一套单独的“发送辅助电源温度/最小变化量/周期发送”设置。

<!-- DOC HelpContext="Mindestaenderung-relativ" -->
###### **相对最小变化量**

在此可以设置再次输出之前所需的相对最小变化量。

<!-- DOC HelpContext="Mindestaenderung-absolut" -->
###### **绝对最小变化量**

在此可以设置再次输出之前所需的绝对最小变化量。

<!-- DOC HelpContext="Status-zyklisch-senden" -->
###### **周期发送状态**

如有需要，状态也可以周期性发送。

### **SC8815 辅助电源**

该页面包含辅助电源（AUX，24–30 V 输出）的设置与上报对象。辅助电源由第二块独立的 SC8815 芯片驱动，其输入电压/电流、输出电压/电流、开关频率与芯片温度都可以独立于总线电源设置与上报。只有使能后，该页面的设置与通信对象才会出现。

#### **使能**

<!-- DOC HelpContext="SC8815-Aktiv" -->
##### **SC8815 辅助电源使能**

在此设置是否使用 SC8815 辅助电源。

选择“是”时，本页面的其它设置以及“辅助电源输入电压”“辅助电源输入电流”“辅助电源状态”“辅助电压”“辅助电流”“辅助电源负载”“辅助电源温度”“辅助电源复位”等通信对象会出现，可以正常使用。

选择“否”时，这些设置和通信对象会被隐藏。已经设置的值仍然保留，重新启用后可以继续使用。

#### **设置**

<!-- DOC HelpContext="SC8815-Hilfsspannung" -->
##### **辅助电源电压**

SC8815 辅助电源（AUX）的输出电压。

可选值：24 V 至 30 V（步进 1 V）。

请根据所连接设备允许的辅助电源电压范围进行选择。

<!-- DOC HelpContext="SC8815-Hilfsstrom" -->
##### **辅助电源电流**

SC8815 辅助电源（AUX）的输出电流上限。

可选值：960 mA、1280 mA、1920 mA、2240 mA。

该值表示辅助电源可供所连接设备使用的最大电流，请根据实际负载进行选择。

<!-- DOC HelpContext="SC8815-Hilfsfrequenz" -->
##### **开关频率**

辅助电源那块 SC8815 芯片的开关频率。

可选值：150 kHz、300 kHz、450 kHz。默认 300 kHz。

两块 SC8815 芯片的开关频率可以分别设置，互不影响。

### **通信对象**

本模块提供以下触发对象与状态对象。总线电源与辅助电源各有一块独立的 SC8815 芯片，因此状态、故障代码、输入电压/输入电流各有两套对象，名称中注明了属于哪一块芯片：

* 总线电源复位 / 辅助电源复位（写入 1 触发对应电源复位；复位时间见“设置 → 复位时间”，仅作用于总线电源）
* 总线电源状态 / 辅助电源状态
* 总线电压、总线电流、总线负载
* 辅助电压、辅助电流、辅助电源负载
* 总线电源输入电压 / 辅助电源输入电压
* 总线电源输入电流 / 辅助电源输入电流
* 总线电源温度 / 辅助电源温度
* 总线/辅助电源 SC8815 运行状态与故障代码

#### **SC8815 状态**

<!-- DOC HelpContext="SC8815-Status" -->
##### **总线电源 / 辅助电源 SC8815 运行状态**

报告对应 SC8815 芯片的运行状态：1 = 正常，0 = 故障。

#### **故障代码**

<!-- DOC HelpContext="SC8815-Fehler" -->
##### **总线电源 / 辅助电源 SC8815 故障代码**

报告对应 SC8815 芯片的故障代码：0 = 无故障。其他代码的含义由固件定义。
